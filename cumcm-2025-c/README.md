# CUMCM 2025 · C 题：NIPT 检测时点优化与胎儿异常判定

**竞赛**：2025 全国大学生数学建模竞赛，广东赛区本科组**二等奖**（证书编号 2504012583，广东省教育厅）
**我的角色**：编程手（三人队，另有建模与写作分工）

## 问题

无创产前检测（NIPT）靠孕妇外周血中的胎儿游离 DNA 判断染色体异常。临床上的检测时点多凭经验按 BMI 分区，缺乏量化依据：太早测不出、要复检，太晚则压缩干预窗口。题目给了 1082 例孕妇的孕周、BMI、Y 染色体浓度、测序质量与 Z 值等数据，要求：

1. 建立 Y 染色体浓度与孕周、BMI 的定量关系；
2. 按 BMI 分组，给出各组最佳检测时点并做误差分析；
3. 引入年龄、身高、体重、孕史等多因素进一步细化；
4. 女胎无法用 Y 染色体判定，需用 13/18/21/X 染色体 Z 值等多指标建判别模型。

## 方法

- **数据清洗**：剔除女胎样本与缺失值，用 3σ 原则剔除 GC 含量 / 读段比例异常点，孕周换算为小数周；有效样本 1058 / 1082（约 98%）。
- **关系建模**：多元线性回归做显著性检验（R² ≈ 0.07，线性关系弱），改用 **Logistic 增长模型**刻画浓度随孕周的非线性上升，分组拟合 R² 均 > 0.90。
- **分层与反推**：K-means（肘部法）分低 / 中 / 高 BMI 三组，结合分位数（P90）与阈值反推（4% 阈值）给出各组首次达标孕周。
- **误差评估**：蒙特卡洛模拟 ±0.5% 检测误差，检验推荐时点的稳健性。
- **预测与分类**：决策树做"是否在给定孕周达标"的规则化预测；神经网络融合 X 染色体 Z 值、GC 含量、总读段数、比对比例、BMI，对女胎非整倍体分类（正确率 88.6%）。
