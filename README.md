## 一、MCM/ICM 2026 · Problem D

**题目**：职业体育联盟的经营决策与风险分析（WNBA 扩军周期的球队估值与竞争平衡）

**做了什么**：为球队管理层搭一条可执行的决策链——把"竞争力、球迷影响力、现金流、债务"写成状态变量做动态仿真，输出多情景对比；在薪资帽与阵容约束下用混合整数规划求 10 人最优阵容；用 XGBoost 预测上座与周边需求，SHAP 解释特征贡献，再做敏感性分析。

**关键点**：模型必须是**可审计**的（状态、决策、约束显式），且**可压力测试**（情景参数化），而不是只给一条结论曲线。

## 二、CUMCM 2025 · C 题

**题目**：NIPT（无创产前检测）的检测时点选择与胎儿异常判定

**做了什么**：清洗 1082 例样本（有效 1058 例，约 98%），用多元线性回归与 Logistic 增长模型刻画 Y 染色体浓度随孕周的非线性增长（分组拟合 R² 均 > 0.90）；以 K-means 肘部法把孕妇分为低/中/高 BMI 三组，结合分位数与阈值反推给出各组首次达标孕周；用蒙特卡洛模拟评估 ±0.5% 检测误差的影响；再用决策树做多因素达标预测、神经网络做女胎染色体非整倍体分类（正确率 88.6%）。

**关键点**：从"机制解释"走到"可执行的临床建议"——给出的是不同 BMI 人群各测第几周，而不是只报告相关性。

- 论文：[`cumcm-2025-c/paper/NIPT_detection_time_optimization.pdf`](cumcm-2025-c/paper/NIPT_detection_time_optimization.pdf)（88 页，含附录）
- 代码：[`cumcm-2025-c/code/`](cumcm-2025-c/code/)（按问题 1–4 分目录）
